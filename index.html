Integração e Entrega Contínua

Aprenda como alterações no seu código se transformam automaticamente em site no ar via GitHub Actions.

⚡

1. Continuous Integration (CI)

Sempre que você faz um git push, o GitHub dispara um processo automatizado. Ele valida as alterações, checa a sintaxe e garante que a sua ramificação principal (main) continue estável e sem erros.

🚀

2. Continuous Deployment (CD)

Assim que a validação (CI) é concluída com sucesso, o robô assume a publicação! O código compilado/estático é implantado instantaneamente no servidor do **GitHub Pages** sem nenhuma intervenção manual.

🤖

3. GitHub Actions

É o motor por trás da mágica. A configuração fica dentro do arquivo .github/workflows/deploy.yml. É lá que definimos os gatilhos, o ambiente e os passos que o robô deve seguir.

Criado para a aula prática de CI/CD • Modifique o HTML, dê um Push e veja a mágica acontecer! ♥
